# Guida di stile

## Principi

- **Un problema per capitolo**. Non catalogo tutto ciò che esiste.
- **Codice prima della teoria**. Mostra il codice, poi spiega cosa fa.
- **La verifica è "compila, esegui, funziona"**. Non liste di criteri astratti.
- **Niente liste infinite**. Massimo 5 elementi per lista.
- **Niente meta-libro**. Non scrivere di come scriverai.
- **Niente ripetizioni**. Un concetto si introduce una volta sola.
