# Convenzioni editoriali

## Struttura

Ogni capitolo ha cinque sezioni:

```
Problema → Codice → Spiegazione → Verifica → Riepilogo
```

## Riquadri

- **Nota**: informazioni utili ma non essenziali
- **Attenzione**: errori comuni

## Codice

Il codice nei capitoli deve corrispondere esattamente ai file sorgente del repository. Nessun frammento inventato.
