# Bibliografia

## Scopo

Questo documento raccoglie le fonti di riferimento ufficiali del progetto Sicania. Ogni capitolo del libro dovrebbe citare, quando opportuno, una o più opere presenti in questo elenco.

## Libri fondamentali

- Andrew S. Tanenbaum, *Modern Operating Systems*.
- Abraham Silberschatz, Peter B. Galvin, Greg Gagne, *Operating System Concepts*.
- Remzi H. Arpaci-Dusseau, Andrea C. Arpaci-Dusseau, *Operating Systems: Three Easy Pieces*.
- Brian W. Kernighan, Dennis M. Ritchie, *The C Programming Language*.

## Specifiche tecniche

- Intel® 64 and IA-32 Architectures Software Developer's Manual.
- AMD64 Architecture Programmer's Manual.
- UEFI Specification.
- ACPI Specification.
- System V AMD64 ABI.
- POSIX (IEEE 1003).

## Risorse online

- OSDev Wiki (da utilizzare come riferimento pratico, non come fonte primaria).
- Documentazione ufficiale GCC.
- Documentazione ufficiale Clang/LLVM.
- Documentazione GNU Binutils.

## Politica delle citazioni

- Le specifiche ufficiali hanno priorità assoluta.
- I libri di riferimento supportano la teoria e il contesto.
- Le risorse online integrano la documentazione ma non sostituiscono le fonti primarie.
